## 2. 术语裁决：一个概念一个词

每一对给出我的建议和理由；你拍板，写进 `docs/GLOSSARY.md`。不同意就改，但**一个概念只留一个词**，另一个词要么禁用、要么明确指别的东西。

| 概念 | 建议 | 理由 |
| --- | --- | --- |
| 系统插件（插件中心装的、TH/MVU 那种） | **插件** | 界面叫「插件中心」，`docs/SYSTEM-PLUGIN-INSTALL.md` 全程用「插件」 |
| SillyTavern 扩展（`iris-compat-st-extension` 跑的第三方 ST 扩展） | **扩展**，且只指这个 | 它和「插件」是两个对象，不是同义词；那 1 处「扩展」要核对指的是不是它 |
| 插件的开 / 关 | **启用 / 停用** | 插件中心已用「已启用」；「禁用」留给权限类的「被禁止」，不做开关词；「开启/关闭」只用于面板、抽屉、开关按钮这类界面元素 |
| 一次聊天记录 | **对话** | 92 比 14，且 `docs/USER-GUIDE.md` 已用「对话」；「聊天」只保留在「聊天备份」这种从 ST 沿用的功能名（列入例外表）；「会话」禁用 |
| 一问一答 | **回合**（已裁） | 沿用 |
| 消息列表里第 N 条 | **楼层** | `#0`/`#1` 那个东西 ST 用户叫楼层；「消息」指内容本身。两个词都留，分工写清 |
| 模型接入方 | **提供方**（已裁） | 27 处「供应商」改掉；这是 CC Switch 式连接页（2026-09-09 裁定）的主词，改前先看 `ConnectionsPage` 相关键 |
| 卡 | **角色**（实体）/ **角色卡**（文件）| 「卡片」只留在固定复合词：卡片脚本、卡片存储、卡片界面（都是 ST 语境里的 card）；单独指一张卡时用角色卡 |
| 删 | **删除**（不可逆）/ **移除**（只从列表拿掉，东西还在） | 两个词各有所指；「清除」只用于「清除数据/缓存」 |
| 存 | **保存** | 「存储」是名词，只指 `scope.storage`/卡片存储 |
| 载 | **加载** | 「载入」改掉；「导入」是 import，别动 |

再加一条**句式规则**，用来抓机器味：

- 不用「的的」「进行」「对…进行」；不用全角字母数字（`Ｉｒｉｓ`）；中英夹写时英文两侧留一个半角空格（`{count} 个插件`），但**占位符 `{name}` 两侧的空格要和 en 列一致**（测试会查占位符名字，不查空格，空格靠你眼看）。
- 标点全角（，。：「」），括号用全角（）；数字后的单位半角。
- 一句一个动词，不堆「成功地」「顺利地」。
- 「从未」这种一词状态（`pluginCenterLastLoadedNever: '从未'`，第 3122 行）要看它出现的格子：格子标题是「最近成功加载」时，「从未」读得通；W1 已让内置插件那一行改说「随核心成员包加载」，所以剩下的「从未」只在第三方插件上出现——你在界面上觉得别扭的，记下键名一起改。

## 3. 步骤

### 3.1 把 zh 列导出成一张表（10 分钟）

在仓库根目录：

```
node --input-type=module -e "
import { en, zh } from './apps/iris-web/src/app/i18n/strings.ts'
for (const k of Object.keys(en)) console.log([k, zh[k], en[k]].join('\t'))
" > "$TEMP/zh-sheet.tsv"
```

（`strings.ts` 是纯数据模块，Node 24 直接跑；1 222 行，三列：键 · 中 · 英。）用表格软件开，按「中」列排序，同一概念的不同写法会挨在一起。

### 3.2 写 `docs/GLOSSARY.md`（半天）

1. 把 STRINGS.md §三 的 104 行搬过去作正文（**搬，不是复制**：§三原地留一行「术语以 `docs/GLOSSARY.md` 为准，本节 2026-09-xx 起不再更新」，不删原表——STRINGS.md 是盘点记录）。
2. 追加 §2 拍板后的行，每行三列：英文 · 中文 · 何时用/不用（例：「移除 — 只从列表拿掉，东西还在；不可逆的用删除」）。
3. 加一节「例外表」：沿用 ST 的功能名（聊天备份、世界书、预设、正则）、不翻译的（Top-p、Seed、token）。
4. 加一节「句式规则」，就是 §2 末尾那五条。
5. `docs/README.md` 的文档索引加一行。

### 3.3 改字典（一到两天，看你多挑）

- **只改 `zh` 列**，键名一个不动、`en` 列一个不动。占位符 `{xxx}` 名字必须与 en 一致（`i18n.test.ts:77` 会查）。
- 一次改一个概念（先把 27 个「供应商」全改「提供方」，跑一次测试，提交一次），别混着改；这样红了知道是哪一批。
- 每改一批，跑 `node --test apps/iris-web/tests/i18n.test.ts`。它查：zh 键集 = en 键集；zh 全中文 / en 全非中文；占位符同名；源码里每个 `t('key')` 有键；再加**几句被钉住原文的测试**——第 129 行「core shell copy renders in Chinese」、145 行「sentence builders」、190 行「consent question」、294 行「page-access copy」。这几处**钉的是具体句子**，你改了那句它就红。红了先读断言里钉的是不是**术语**：是术语就把断言改成新词（这是本次的目的）；钉的是句意（比如同意问句必须同时说出两条规则）就保句意改措辞。**不许为了变绿把断言删掉。**
- 「从未」类别扭句：同一提交里改，提交说明列出键名。

- 一个概念一个提交；`docs/GLOSSARY.md` 单独一个提交放最前面，这样 PR 的第一屏就是裁决表。
